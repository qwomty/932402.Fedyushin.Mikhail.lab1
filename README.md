# 932402.Fedyushin.Mikhail.lab1
## Особенности реализации
* **Семантическая разметка:** Использование основных тегов HTML5 (`header`, `main`, `section`, `aside`, `footer`).
* **Контент:**
  * Шапка с фотографией профиля и краткой информацией.
  * Блок навыков (маркированный список `<ul>`).
  * Блок избранных проектов (нумерованный список `<ol>`).
  * Боковая панель (`<aside>`) с информацией о любимом студийном оборудовании и жанрах.
  * Интерактивная форма обратной связи с полями для имени, email и текста сообщения, а также обязательными атрибутами `name`, `placeholder` и `required`.
* **Оформление:** Пользовательские стили выполнены в глубоких сине-фиолетовых тонах (студийная эстетика) с помощью встроенного блока `<style>`.
